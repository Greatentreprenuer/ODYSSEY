# 🚀 How to Make Your Odyssey Website Live

Since your website is built with static files (HTML, CSS, JS), you can host it for free and make it public in minutes. Here are the three best ways:

## Option 1: Netlify (Easiest - Drag & Drop)
This is the fastest method. No coding or Git required.

1.  **Go to [Netlify Drop](https://app.netlify.com/drop)**.
2.  **Drag and drop** your `ODYSSYE` folder (or the `odyssey_launch.zip`) onto that page.
3.  **Done!** Your site will be live instantly.

---

## Option 2: GitHub Pages (Professional - Recommended)
Best if you want to keep track of changes.

1.  **Create a Repository**: Go to GitHub and create a new repository called `odyssey`.
2.  **Upload Files**: Drag and drop your project files or use Git to push them.
3.  **Enable Pages**: Go to **Settings** -> **Pages**, set the branch to `main`, and click **Save**.
4.  **Wait**: Your site will be live at `https://your-username.github.io/odyssey/`.

---

## Option 3: Vercel (Developer Choice)
Vercel is extremely fast and high-performance.

1.  **Connect GitHub**: Sign in to [Vercel](https://vercel.com) using your GitHub account.
2.  **Import Project**: Select your `odyssey` repository.
3.  **Deploy**: Vercel will automatically detect it's a static site and build it.
4.  **Done!** Your site is live at `odyssey.vercel.app`.

---

## 🛠 Pre-Flight Checklist
- [ ] **Asset Paths**: Ensure all image and video links are relative (e.g., `videos/bg.mp4`).
- [ ] **Waitlist IDs**: Ensure your Google Form IDs are replaced in `waitlist.html`.
- [ ] **Success Check**: Open `index.html` locally one last time to ensure everything loads.
